# `course-2026` is the default branch for the semester

For the *Complex Web Services* course, 2026–27, about twenty students fork OcéEns and fork its default branch, so `course-2026` becomes the repository's default branch: forks start from it and pull requests target it (including the development sign-in, #82, and the per-role seed, #84). `main` is not touched during the semester, to give students a stable base and keep course-specific code out of it; no `main` → `course-2026` synchronisation is planned before the end of the semester.
